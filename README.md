# Google Cybersecurity certificate exercises

This repository holds coursework and practice exercises I completed while studying for the [Google Cybersecurity Professional Certificate](https://www.coursera.org/professional-certificates/google-cybersecurity).

The files cover incident handling, NIST-based incident response, Linux permissions, SQL filtering, a small Python algorithm and a security audit.

These are **training scenarios**, not reports from a real employer or production incident. The exercises include prompts supplied by the course as well as my responses. I've kept the original exercise files for reference.
